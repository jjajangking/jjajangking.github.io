채널 운영자가 승인한 릴스 원본을 건강줍줍 YouTube Shorts로 전송하고 처리 결과를 확인하는 Mac용 도구입니다.

개인정보처리방침 읽기 ↗

01 · 게시 순서

릴스와 Threads 확인 후 전송

정기 자동 게시가 활성화된 회차에는 인스타그램 릴스와 Threads 글의 게시를 확인한 뒤 유튜브 전송을 준비합니다. 운영자는 60초 동안 제목, 설명, 공개 범위, 아동용 여부를 수정하거나 해당 회차를 보류할 수 있습니다.

02 · 계정 연결

채널 운영자 전용

이 도구는 YouTube API 서비스를 사용합니다. 채널 운영자가 개인정보처리방침에 동의한 뒤 Google 동의 화면에서 영상 업로드와 채널 조회 권한을 부여합니다. 이 공개 안내 페이지에서는 계정을 연결하거나 영상을 올릴 수 없습니다.
